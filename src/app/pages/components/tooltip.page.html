Simple

Bungkus trigger dan tooltip dalam grup hover.

Simpan perubahan

Group

Beberapa trigger dalam satu baris.

@for ( item of [ { label: 'Edit', icon: 'pencil', tip: 'Edit item' }, { label: 'Duplikat', icon: 'copy', tip: 'Duplikat item' }, { label: 'Hapus', icon: 'trash-2', tip: 'Hapus permanen' }, ]; track item.label ) { {{ item.tip }} }

Positions

Top, right, bottom, dan left.

@for (position of ['top', 'right', 'bottom', 'left']; track position) { Tooltip {{ position }} }

Disabled

Tooltip bisa dinonaktifkan, atau dipasang pada tombol disabled.

Tidak akan muncul Fitur belum tersedia di paket Anda

Template

Konten tooltip bisa lebih kaya dari satu baris.

Nimbus Pro Anggota tak terbatas, analitik lanjutan, dan dukungan prioritas. Tekan ⌘K untuk mencari fitur.
