API

Input utama komponen calendar.

Properti Tipe Default Deskripsi
mode 'single' | 'multiple' | 'range' 'single' Jenis pemilihan tanggal.
showSelectors boolean false Menampilkan select bulan dan tahun di header.
value Date[] [] Tanggal terpilih; dua nilai untuk range.
