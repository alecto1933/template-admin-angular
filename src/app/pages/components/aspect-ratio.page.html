Potret & story

Rasio vertikal untuk konten sosial, katalog, atau preview aplikasi mobile.

Penggunaan

Bungkus media dengan komponen dan isi kelas size-full object-cover pada gambar. 

<!-- Nilai number -->
<ui-aspect-ratio [ratio]="16 / 9" class="rounded-xl">
  <img
    src="demo/landscape.svg"
    alt="Deskripsi gambar"
    class="size-full object-cover"
  />
</ui-aspect-ratio>

<!-- Nilai string CSS -->
<ui-aspect-ratio ratio="3 / 4">
  <img src="foto.jpg" alt="..." class="size-full object-cover" />
</ui-aspect-ratio>

Aksesibilitas

Aspect ratio hanya mengatur ruang; semantik media tetap di konten.

  • Setiap <img> wajib punya alt; gunakan alt="" untuk gambar dekoratif.
  • object-cover memotong media. Pastikan bagian penting tidak berada di tepi.
  • Video harus punya kontrol atau tombol dengan aria-label yang jelas.
  • Rasio tetap mencegah pergeseran layout (CLS) saat media selesai dimuat.

API

Satu input, tanpa logika JavaScript tambahan.

Properti Tipe Default Deskripsi
ratio number | string 16 / 9 Nilai CSS aspect-ratio; string seperti '3 / 4' juga diterima.
class host class — Tambahkan rounded-*, border, atau posisi relatif langsung di host.
