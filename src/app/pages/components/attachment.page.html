Ukuran

Tiga ukuran: sm, md (default), dan lg.

Dengan gambar

Gunakan input image untuk menampilkan thumbnail. Ikon tetap dipakai bila gambar tidak tersedia.

State

Status unggah ditampilkan lewat ikon, teks, dan progress bar — bukan hanya warna.

Group

Bungkus beberapa lampiran dengan ui-attachment-group untuk membuat satu daftar berbagi border.

Trigger

Tambahkan input interactive agar seluruh baris bisa diklik dan diakses lewat keyboard.

Saat baris bersifat interaktif, jangan menaruh tombol aksi di dalamnya. Gunakan baris biasa untuk lampiran yang punya aksi unduh/hapus.

Penggunaan

Konten aksi diproyeksikan langsung ke dalam komponen.

<ui-attachment
  name="invoice.pdf"
  description="PDF · 2,4 MB"
  icon="file-text"
  state="done"
>
  <button uiButton size="icon-sm" aria-label="Unduh">
    <ui-icon name="download" />
  </button>
</ui-attachment>

<ui-attachment-group>
  <ui-attachment size="sm" name="logo.svg" />
  <ui-attachment size="sm" name="brand.pdf" />
</ui-attachment-group>

<ui-attachment
  interactive
  name="invoice.pdf"
  (activated)="open()"
/>

Aksesibilitas

Perilaku yang sudah ditangani oleh komponen.

  • Mode interaktif memberi role="button", tabindex="0", dan dukungan Enter/Space.
  • Tombol aksi memakai <button> dengan aria-label dan tidak memicu aksi trigger.
  • Progress unggah memakai role="progressbar" dengan aria-valuenow.
  • Nama file panjang dipotong secara visual, tetapi tetap tersedia lewat atribut title.

API

ui-attachment-group tidak punya input; cukup bungkus beberapa lampiran.

Properti Jenis Tipe Default Deskripsi
name input string wajib Nama atau judul file.
description input string '' Metadata singkat: tipe, ukuran, status.
icon input IconName 'file-text' Ikon saat tidak memakai thumbnail.
image input string | null null URL thumbnail gambar.
size input 'sm' | 'md' | 'lg' 'md' Ukuran baris lampiran.
state input 'idle' | 'uploading' | 'processing' | 'done' | 'error' 'idle' Status unggah dan tampilan feedback.
progress input number 0 Persentase progress bar saat state uploading.
interactive input boolean false Membuat seluruh baris menjadi trigger.
activated output void — Dipancarkan saat baris interaktif diklik atau ditekan.
