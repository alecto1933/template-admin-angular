Penggunaan

Bubble adalah styling attribute; alignment dan varian diatur lewat data attribute. 

<span uiBubble data-align="start" data-variant="default">
  Pesan untuk penerima.
</span>

<span uiBubble data-align="end" data-variant="primary">
  Balasan pengirim.
  <span class="ui-bubble-time">10:20</span>
</span>

<div uiBubbleGroup>
  <span uiBubble data-align="start">Satu</span>
  <span uiBubble data-align="start">Dua</span>
</div>
