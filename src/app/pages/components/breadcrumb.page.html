Penggunaan

Susun breadcrumb dari elemen semantik nav > ol > li. 

<nav aria-label="Breadcrumb">
  <ol uiBreadcrumbList>
    <li uiBreadcrumbItem>
      <a uiBreadcrumbLink href="/">Beranda</a>
    </li>

    <li uiBreadcrumbSeparator aria-hidden="true">/</li>

    <li uiBreadcrumbItem>
      <button uiBreadcrumbLink>
        Komponen
        <ui-icon name="chevron-down" />
      </button>
    </li>

    <li uiBreadcrumbSeparator aria-hidden="true">/</li>

    <li uiBreadcrumbItem>
      <span uiBreadcrumbPage aria-current="page">
        Breadcrumb
      </span>
    </li>
  </ol>
</nav>

API

Atribut CSS untuk menyusun breadcrumb.

Atribut Elemen Deskripsi
uiBreadcrumbList <ol> Flex row, gap, dan ukuran teks breadcrumb.
uiBreadcrumbItem <li> Item breadcrumb; mendukung tautan, tombol, atau teks.
uiBreadcrumbLink <a> / <button> Warna muted dengan hover dan focus ring.
uiBreadcrumbPage <span> Halaman aktif; gunakan bersama aria-current="page".
uiBreadcrumbSeparator <li> Pembatas; sembunyikan dari pembaca layar dengan aria-hidden.
