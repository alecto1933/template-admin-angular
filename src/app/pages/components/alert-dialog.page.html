Konfirmasi dasar

Minta persetujuan sebelum melanjutkan aksi. Tombol Batal menerima fokus pertama.

Anda masih bisa mengubahnya kembali nanti lewat halaman Pengaturan.

Aksi destruktif

Gunakan varian tombol destructive dan jelaskan konsekuensinya di dalam dialog.

Tindakan ini tidak dapat dibatalkan. Ekspor data terlebih dahulu jika masih diperlukan.

Konten tambahan

Panel bisa memuat peringatan, daftar, atau checkbox sebelum pengguna menyetujui.

Waktu publikasi akan dicatat di riwayat aktivitas workspace.

Penggunaan

Buka lewat template reference; konfirmasi dan pembatalan dikirim sebagai output. 

<button uiButton (click)="dialog.open()">
  Hapus proyek
</button>

<ui-alert-dialog
  #dialog
  title="Hapus proyek ini?"
  description="Data akan dihapus permanen."
  confirmLabel="Hapus proyek"
  confirmVariant="destructive"
  (confirmed)="remove()"
  (cancelled)="onCancel()"
>
  <div uiAlert data-variant="danger">
    <ui-icon name="triangle-alert" />
    Tindakan ini tidak bisa dibatalkan.
  </div>
</ui-alert-dialog>

Aksesibilitas

Perilaku yang sudah ditangani komponen.

  • Memakai role="alertdialog" dengan aria-labelledby dan aria-describedby.
  • Fokus awal jatuh ke tombol Batal, sehingga aksi destruktif tidak langsung terpicu oleh Enter.
  • Klik backdrop diabaikan. Menutup dengan ESC dianggap sebagai pembatalan.
  • Tidak ada tombol X: pengguna harus memilih salah satu aksi secara eksplisit.

API

Komponen membungkus ui-dialog dan menambahkan perilaku konfirmasi.

Properti Jenis Tipe Default Deskripsi
title input string wajib Judul dialog.
description input string '' Penjelasan singkat di bawah judul.
confirmLabel input string 'Lanjutkan' Teks tombol konfirmasi.
cancelLabel input string 'Batal' Teks tombol pembatalan.
confirmVariant input 'primary' | 'destructive' 'primary' Varian warna tombol konfirmasi.
confirmed output void — Dipancarkan saat pengguna menekan konfirmasi.
cancelled output void — Dipancarkan saat Batal, ESC, atau close programatik.
open() method void — Menampilkan dialog.
close() method void — Menutup dialog secara programatik.
