Variants

Pilih varian sesuai tingkat kepentingan aksi.

Size

Ukuran sm, default, lg, dan ikon.

With icon

Ikon membantu mempercepat pemindaian aksi.

Rounded

Tambahkan rounded-full untuk tombol pill.

Spinner

Gunakan input loading untuk menonaktifkan tombol dan menampilkan spinner.

As anchor

Atribut uiButton juga bekerja pada <a>.

Buka dokumentasi Lihat repositori Pelajari lebih lanjut

Penggunaan

Satu directive, banyak varian.

<button uiButton>Simpan</button>
<button uiButton variant="outline" size="sm">Batal</button>
<button uiButton loading>Menyimpan…</button>

<a uiButton variant="outline" href="/docs">
  Dokumentasi
</a>

<button uiButton size="icon" aria-label="Tambah">
  <ui-icon name="plus" class="size-4" />
</button>
