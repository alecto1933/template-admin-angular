Empat tingkat kepentingan

Gunakan varian yang sesuai: informasi netral, konfirmasi, peringatan, atau kegagalan.

Informasi

Data disinkronkan otomatis setiap 5 menit. Perubahan terakhir 2 menit lalu.

Berhasil

Profil workspace berhasil disimpan dan langsung diterapkan ke semua anggota tim.

Perhatian

Kuota unggahan tersisa 12% dari total paket. Hapus file lama atau upgrade penyimpanan.

Pembayaran gagal

Kartu ditolak oleh penyedia pembayaran. Periksa detail kartu atau gunakan metode lain.

Dengan aksi

Alert bisa memuat tombol untuk menyelesaikan masalah langsung dari pesannya.

Stok hampir habis

Produk “Kaos Alecto” tersisa 4 unit.

Sinkronisasi gagal

Koneksi ke penyedia pembayaran terputus sejak 10 menit lalu.

Bisa ditutup

Tombol tutup memberi kontrol ke pengguna. Gunakan aria-label pada tombolnya.

@for (alert of dismissible(); track alert.id) {

{{ alert.title }}

{{ alert.message }}

} @empty {

Semua alert ditutup

Tampilkan lagi untuk mengulang demo.

}

Tanpa ikon

Untuk pesan singkat, ikon opsional. Tetap sertakan teks yang jelas — jangan hanya mengandalkan warna.

Mode maintenance dijadwalkan Sabtu, 22.00 WIB selama 30 menit.

Semua invoice bulan ini sudah dibayar. Tidak ada tagihan tertunda.

Akun dim@alecto.id gagal login 5 kali. Sesi diblokir sementara.

Penggunaan

Cukup tambahkan atribut uiAlert dan data-variant. 

<div uiAlert data-variant="warning" role="status">
  <ui-icon
    name="triangle-alert"
    class="mt-0.5 size-4 shrink-0"
  />

  <div class="min-w-0 flex-1">
    <p class="font-semibold">Stok menipis</p>
    <p class="mt-0.5">Tersisa 4 unit.</p>

    <button uiButton variant="outline" size="sm">
      Perbarui stok
    </button>
  </div>
</div>

Aksesibilitas

Aturan singkat saat memakai alert.

  • Gunakan role="alert" hanya untuk pesan penting yang muncul setelah aksi pengguna.
  • Untuk informasi non-kritis, gunakan role="status" agar tidak menginterupsi screen reader.
  • Selalu sertakan teks dan ikon; warna saja tidak cukup untuk membedakan tingkat kepentingan.
  • Tombol tutup wajib punya aria-label yang menjelaskan aksinya.

API

Alert adalah directive styling; konten dan ikon diproyeksikan manual.

Atribut Tipe Nilai Default Deskripsi
uiAlert atribut — — Menerapkan layout, border, dan padding alert.
data-variant string 'info' | 'success' | 'warning' | 'danger' 'info' Mengatur warna latar, border, dan teks.
role string 'status' | 'alert' — Semantik live region; pilih sesuai urgensi pesan.
