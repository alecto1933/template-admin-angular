Penggunaan

Setiap anak langsung dari ui-carousel menjadi satu slide. 

<ui-carousel [slides]="3" [spacing]="16" size="md">
  <article>Slide 1</article>
  <article>Slide 2</article>
  <article>Slide 3</article>
</ui-carousel>

<ui-carousel orientation="vertical" [spacing]="12">
  ...
</ui-carousel>

API

Input carousel.

Properti Tipe Default Deskripsi
slides number 3 Jumlah slide yang terlihat (horizontal).
spacing number 16 Jarak antar slide dalam px.
orientation 'horizontal' | 'vertical' 'horizontal' Arah geser carousel.
size 'sm' | 'md' | 'lg' 'md' Tinggi minimum slide.
ariaLabel string 'Carousel' Label region carousel.
