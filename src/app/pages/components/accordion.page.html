Penggunaan

API sederhana: satu komponen induk dan item yang diproyeksikan.

<ui-accordion type="multiple">
  <ui-accordion-item
    title="Judul panel"
    [open]="true"
  >
    Konten panel di sini.
  </ui-accordion-item>

  <ui-accordion-item title="Panel lain">
    Konten panel lain.
  </ui-accordion-item>
</ui-accordion>

Aksesibilitas

Perilaku yang sudah ditangani tanpa konfigurasi tambahan.

  • Trigger memakai elemen button, jadi bisa diakses dengan Tab, Enter, dan Space.
  • aria-expanded dan aria-controls menandai state panel.
  • Panel tertutup diberi inert, sehingga tautan di dalamnya tidak bisa difokus.
  • Animasi tinggi mengikuti pengaturan prefers-reduced-motion.

API

Semua input bersifat opsional kecuali title.

Komponen Input Tipe Default Deskripsi
ui-accordion type 'single' | 'multiple' 'single' Menentukan berapa panel yang boleh terbuka.
ui-accordion collapsible boolean true Pada mode single, izinkan panel aktif ditutup.
ui-accordion-item title string wajib Teks pada trigger.
ui-accordion-item open boolean (two-way) false State panel; mendukung [(open)].
ui-accordion-item disabled boolean false Menonaktifkan trigger dan mengurangi opacity item.
