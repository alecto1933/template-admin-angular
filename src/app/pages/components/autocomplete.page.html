Tombol hapus muncul saat ada teks atau pilihan. Ikon pencarian selalu ada di kiri input.

Klik ikon X untuk mengosongkan nilai dan filter.

Disabled

Input tidak bisa difokus, dibuka, atau diubah.

Nilai tetap terlihat meskipun input dinonaktifkan.

Invalid

State error memakai border dan ring merah, plus pesan yang terhubung ke input.

Framework wajib dipilih.

Auto highlight

Opsi pertama otomatis aktif saat dropdown dibuka, sehingga Enter langsung memilihnya.

Coba fokus ke input, lalu tekan Enter tanpa memilih apa pun.

Auto highlight (search)

Selain auto-highlight, teks yang cocok dengan pencarian disorot di dalam opsi.

Cocokkan teks untuk melihat highlight di daftar.

With groups

Isi properti group pada option untuk mengelompokkan hasil.

Header grup tidak ikut terpilih saat navigasi.

With group and separators

Tambahkan separators untuk garis pemisah antar opsi dalam grup.

Async search

Filter dilakukan di server: komponen hanya mengirim query dan menampilkan state loading.

Penggunaan

Dua mode: standalone dengan two-way binding, atau reactive form lewat ControlValueAccessor. 

<!-- Standalone -->
<ui-autocomplete
  [options]="frameworks"
  [(value)]="selected"
  [clearable]="true"
  [autoHighlight]="true"
  placeholder="Cari framework…"
/>

<!-- Reactive form -->
<ui-autocomplete
  formControlName="framework"
  [options]="frameworks"
  [invalid]="control.invalid && control.touched"
/>

<!-- Async -->
<ui-autocomplete
  [options]="results()"
  [loading]="loading()"
  [filterLocally]="false"
  (searchChange)="search($event)"
/>

Aksesibilitas

Pola combobox mengikuti ARIA Authoring Practices.

  • Input memakai role="combobox", aria-expanded, aria-controls, dan aria-activedescendant.
  • Navigasi Arrow Up/Down, Home/End, Enter, Escape, dan Tab sudah ditangani; opsi nonaktif dilewati.
  • Tombol clear punya aria-label; input memakai aria-busy saat async search berjalan.
  • Header grup memakai teks, bukan elemen option, sehingga tidak ikut terbaca sebagai pilihan.

API

Semua input opsional kecuali options.

Properti Jenis Tipe Default Deskripsi
options input AutocompleteOption[] [] Daftar pilihan; mendukung value, label, description, disabled, group.
value input (two-way) string '' Nilai terpilih; terhubung ke ControlValueAccessor.
placeholder input string 'Cari…' Placeholder input.
inputId input string auto ID input untuk dihubungkan dengan label.
ariaLabel input string | null null Label aksesibel bila tidak ada teks label visual.
emptyText input string 'Tidak ada hasil' Pesan saat daftar kosong.
disabled input boolean false Menonaktifkan input.
invalid input boolean false Menampilkan state error.
clearable input boolean false Menampilkan tombol clear.
autoHighlight input boolean false Mengaktifkan opsi pertama secara otomatis.
highlightMatch input boolean false Menyorot teks yang cocok dengan query.
separators input boolean false Garis pemisah antar opsi dalam grup.
allowCustom input boolean false Mengizinkan teks bebas di luar daftar.
filterLocally input boolean true Matikan untuk async search di server.
loading input boolean false Menampilkan spinner dan aria-busy.
searchChange output string — Dipancarkan saat teks pencarian berubah.
optionSelected output AutocompleteOption — Dipancarkan saat opsi dipilih.
