Size

Ukuran memengaruhi padding dan skala judul.

Small

Ringkas untuk sidebar.

Padding lebih rapat dan judul lebih kecil.

Default

Ukuran standar.

Cocok untuk sebagian besar konten dashboard.

Large

Untuk konten utama.

Padding lega dan ruang napas lebih banyak.

Spacing

Atur kerapatan vertikal lewat data-spacing.

Compact

Jarak antar bagian rapat.

Ideal untuk daftar pengaturan.

Default

Spacing seimbang.

Pilihan aman untuk konten umum.

Relaxed

Lebih lega.

Untuk kartu promosi atau onboarding.

Image

Gabungkan dengan ui-aspect-ratio untuk gambar di bagian atas.
