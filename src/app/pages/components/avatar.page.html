Penggunaan

Avatar adalah styling attribute; grup dan badge memakai container terpisah. 

<span uiAvatar class="bg-primary-soft text-primary">
  RP
</span>

<span uiAvatar>
  <img src="avatar.jpg" alt="Nama" class="size-full object-cover" />
</span>

<div uiAvatarGroup>
  <span uiAvatar data-size="sm">RP</span>
  <span uiAvatar data-size="sm">DL</span>
  <span uiAvatar data-size="sm">+6</span>
</div>

<span class="relative inline-flex">
  <span uiAvatar>RP</span>
  <span uiAvatarBadge class="bg-success"></span>
</span>

API

Atribut CSS yang tersedia.

Atribut Nilai Default Deskripsi
uiAvatar atribut — Container avatar; ukuran default 40px.
data-size xs | sm | lg | xl md Ukuran avatar.
uiAvatarGroup atribut — Tumpuk avatar dengan jarak negatif dan ring.
uiAvatarBadge atribut — Badge absolut; letakkan di dalam wrapper relative inline-flex.
